        Apakah Anda yakin ingin menghapus data ini?

        Koneksi Google Apps Script (GAS)
        Status: Mode Penyimpanan Lokal (Offline)
        Aplikasi sedang menggunakan memori lokal browser. Data dapat disimpan dan diuji langsung.
        Pastikan URL berakhiran /exec (bukan /dev atau link editor).

        1. Buka Google Sheets → Ekstensi → Apps Script (atau buka script.google.com).
        2. Salin seluruh kode dari file Code.gs terbaru dan simpan di editor Apps Script.
        3. Penting: Pada dropdown fungsi di atas, pilih fungsi initDatabase lalu klik tombol Jalankan (Run) sekali. Ikuti petunjuk untuk Review Permissions → Advanced → Go to ... (unsafe) → Allow untuk mengizinkan script mengakses Sheet & Drive Anda.
        4. Klik tombol Terapkan (Deploy) di kanan atas → Kelola deployment (Manage deployments) → klik ikon pensil (Edit) → pada Versi pilih Versi baru (New version).
        5. Pastikan pengaturan:
          • Jalankan sebagai (Execute as): Saya / Me (email Google Anda)
          • Yang memiliki akses (Who has access): Siapa saja / Anyone (Wajib agar tidak error CORS!)
        6. Salin URL Aplikasi Web yang berakhiran /exec, tempelkan pada kolom di atas, lalu klik Uji Koneksi & Simpan.
